# Official Assets

Drop authentic PT Hidro Dinamika Internasional media here.

## Required

- `logo.png` — the official HDI logo (H₂ droplet mark). The navigation and
  footer automatically render this file as soon as it exists; until then a
  neutral typographic wordmark is shown. **Never redraw or substitute the
  official logo.**

## Recommended structure

- `images/` — company, product and event photography
- `models/` — GLB/GLTF 3D models of real HDI hardware (Draco-compressed)
- `videos/` — compressed MP4/WebM footage

Every media mount point in the codebase (`TechnologyMedia`, hero scene,
program entries) is built to accept real assets without layout changes.
